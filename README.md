# The Last Train

A 2D horror platform game. Open `index.html` in a modern browser to play. The game uses HTML Canvas and JavaScript; the background music streams online, so music requires an internet connection.

## Files

- `index.html` — game page and interface
- `style.css` — visual styling
- `game.js` — game logic, drawing, controls, enemies, and level progression

Keep these three files together in the same folder. No build tools or installation are required.

## Controls

- **A / D** or **← / →** — move
- **Space** — jump
- **E** — interact, collect clues, and advance dialogue
- **Mouse + left click** — aim and fire after getting the gun
- **Music button** — mute or restore music

## Game outline

Explore the station and two train coaches, solve the number and colour locks, then enter the nightmare. There are nine distinct spike-platform sections, two monster gauntlets, a long chase, and two boss battles. Find the key and portal after clearing the final monster wave. Defeat The Hollow to see the ending credits.

## Publish with GitHub Pages

1. Create a new repository on GitHub.
2. Upload `index.html`, `style.css`, `game.js`, and this README to the repository's top level.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select the `main` branch and `/ (root)`, then save.
5. After GitHub Pages finishes publishing, the Pages section will show the public game link.
